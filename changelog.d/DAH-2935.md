### Fixed
- `lium provider status`, `lium provider node list` and `lium provider billing list` now scope the portal's global listings (`GET /executors`, `GET /billing`) to the active hotkey, so a provider sees only its own nodes and billing rows (previously other providers' machines and charges were reported as the caller's). `node list --all` and `billing list --all` return the unfiltered listing; `--miner-hotkey` still targets one provider. Scripts that relied on the unfiltered default must add `--all`. (DAH-2935)
