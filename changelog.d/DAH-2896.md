### Changed
- The SDK records where the API key came from (`env:LIUM_API_KEY` or `config:~/.lium/config.ini [api] api_key`). 401 and 403 errors now end with `key <first 6>…<last 4> from <source>`, and an insufficient-balance 403 shows the required and available amounts when the server provides them.
- `lium balance` prints the key fingerprint and source (also in `--json` as `api_key_fingerprint` / `api_key_source`); `lium config get` prints where the value was read from.

### Fixed
- The SDK (`Config.load()`, used by every CLI command) now honours the SSH key the CLI is configured with: `LIUM_SSH_KEY_PATH`, then `[ssh] key_path` from `~/.lium/config.ini` (what `lium init` writes), then the previous `~/.ssh/id_ed25519|id_rsa|id_ecdsa` probing. `Config.ssh_key_source` says which one was used; `resolve_ssh_key_path()` is public.
- The SDK accepts `LIUM_API_API_KEY` ahead of `LIUM_API_KEY`, the same order as `lium config get api.api_key`, so the two can no longer resolve different keys.
